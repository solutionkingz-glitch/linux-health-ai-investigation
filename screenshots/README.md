## Investigation Flow

The screenshots provide evidence of the complete workflow:

**Monitor → Detect → Classify → Alert → Investigate → Analyse → Recommend → Verify**

The project combines Bash-based Linux health monitoring with Claude Code to support structured incident investigation and root-cause analysis.
